# px-repo-template

Standardized template for PX repositories. Use this to generate new PX repos with consistent governance, CI, dependabot, and MIT licensing.

## Included
- SECURITY.md, CODE_OF_CONDUCT.md, CONTRIBUTING.md, LICENSE (MIT)
- .github/dependabot.yml, .github/workflows/ci.yml

## Generate a new repo
Use the "Use this template" button on GitHub, then rename to follow the `px-{category}-{name}` convention.
